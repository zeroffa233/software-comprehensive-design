# 接口规范总则

> 东南大学 计算机科学与技术专业 · 软件开发综合课程设计 ｜ 小组
> 全组接口设计必须遵循本总则；各模块 api-*.md 在此基础上细化。与 DESIGN.md §8 一致，冲突时以 DESIGN.md 为准。

## 1. 基础约定

| 项 | 约定 |
|---|---|
| 统一前缀 | 所有业务接口 `/api/v1/`；后续大版本升 `/api/v2/`，不破坏 v1 |
| 风格 | RESTful 资源命名（名词复数），动作类操作用动词子路径（如 `/api/v1/orders/{id}/pay`） |
| 请求体/响应体 | JSON（UTF-8）；时间统一 `yyyy-MM-dd HH:mm:ss`（服务器时区 UTC+8） |
| 鉴权 | 登录、验证码接口外一律携带请求头 `Authorization: Bearer {token}`（JWT） |
| 内容类型 | `application/json`；图片上传走 `multipart/form-data` |

## 2. 统一返回结构

所有接口返回 `{code, msg, data}`：

| 字段 | 类型 | 说明 |
|---|---|---|
| code | int | `0` 成功；非 0 见错误码表 |
| msg | string | 提示信息，可直接展示给用户或前端 toast |
| data | object/array/null | 业务数据；失败时为 null |

成功示例：

```json
{ "code": 0, "msg": "success", "data": { "goodsId": 1001, "title": "高数教材（第七版）" } }
```

## 3. 错误码表（全组统一）

| code | 含义 | 典型场景 |
|---|---|---|
| 0 | 成功 | — |
| 400 | 参数非法 | 缺参、格式错误、超出范围 |
| 401 | 未登录 / Token 失效 | 未携带 JWT、Token 过期、主动退出后旧 Token |
| 403 | 权限不足 / 非资源属主 | 普通用户调管理接口；编辑他人商品 |
| 404 | 资源不存在 | 商品已删除、订单号错误 |
| 409 | 业务状态冲突 | 重复下单、库存不足、手机号已注册 |
| 423 | 账号状态受限 | 账号被封禁、密码连续错误锁定 |
| 429 | 请求过于频繁 | 验证码 60 秒内重复获取 |
| 5000 | 服务器内部错误 | 未捕获异常（msg 不暴露堆栈） |
| 4001 | Agent 参数非法 | MCP 报文 params 非法（Agent-Skill-MCP 专用） |
| 4003 | Agent 权限不足 | 超出 agent-svc Skill 允许操作 |
| 5000(Agent) | Agent 业务错误 | Skill 转发业务 API 失败 |

## 4. JWT 规则

- 载荷：`uid`、`role`（USER/ADMIN/AGENT_SVC）、`iat`、`exp`；签名密钥只放服务端环境变量，严禁入库（.gitignore 已挡 `.env`）。
- 有效期：访问 Token 2 小时；服务端在 Redis 记录会话（`session:{uid}`），封禁/退出/改密时主动失效。
- 校验链路：网关过滤器解析 JWT → 校验 Redis 会话 → 注入当前用户上下文 → `@RequireRole` 注解做角色校验 → 资源属主校验在 Service 层比对 `user_id`。
- 账号封禁：登录接口返回 423 并附封禁原因摘要；已签发 Token 由管理端封禁操作触发 Redis 失效。

## 5. 分页约定

- 请求参数：`page`（默认 1，从 1 开始）、`pageSize`（默认 10，最大 50）。
- 响应 `data` 分页结构：

```json
{
  "list": [],
  "total": 123,
  "page": 1,
  "pageSize": 10
}
```

- 列表接口（商品搜索、订单列表、操作日志等）一律遵守；排序参数只允许白名单字段（如 `sort=price,asc`）。

## 6. 其他通用规则

- 幂等：创建类接口支持客户端生成 `requestId` 防重复提交（下单必带）。
- 文件：商品图片上传返回相对 URL，由静态映射（Nginx/local）访问；单张 ≤5MB，仅 jpg/png/webp。
- 日志：管理员关键操作、Agent 调用分别落 `admin_op_log`、`agent_chat_log`（详见 DESIGN.md §6、§7）。
- 各模块端点细化见：design/api-用户及权限.md、design/api-商品发布.md、design/api-购物交易.md（初稿 · 待课次4校准）。
